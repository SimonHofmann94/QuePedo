# German glossary for Spanish grammar content

Injected into every chapter-translation prompt so 78 independently translated
chapters don't drift into three different words for the same tense.

## Traps

- **Never** call a stem-changing verb *diphthongierend*. That is only true for
  e → ie and o → ue; the e → i class (`pedir → pido`, `servir → sirvo`) has no
  diphthong at all. Say *Verb mit Stammwechsel*, and name the classes as
  `e → ie / o → ue / e → i`.
- German *Tilde* means `~`, so writing "Akzent (tilde)" invites a reader to think
  of the ñ squiggle. Mark the Spanish word as Spanish.
- Do not carry English mnemonics across. "Boot verbs" / "shoe verbs" means
  nothing in German — drop it rather than translating it.

## Register
Address the learner with **du**. Use "man" for generic statements, not "wir".
Keep sentences short — this is reference material a beginner reads on a phone.
